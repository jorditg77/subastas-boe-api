# Métricas semanales — seguimiento de tracción

Rellenar **una fila por semana** (ej. cada lunes, 10 min). Fuentes gratuitas:

| Fuente | Dónde | Qué mirar |
|---|---|---|
| RapidAPI Analytics | Studio → tu API → Analytics | Suscriptores por plan, llamadas, errores |
| Zyla | Panel de proveedor | Suscriptores, llamadas (cuando aprueben la API) |
| UptimeRobot | Dashboard | % uptime del mes |
| Google Search Console | Rendimiento | Impresiones, clics, consultas top |
| GitHub | Repo → Insights | Estrellas, visitas únicas |

**MRR neto** = suscriptores × precio × 0,80 (RapidAPI y Zyla retienen 20%).
Objetivo del plan: **~330 €/mes netos** (≈ 10-12 suscriptores mezcla Starter/Pro).
Hito intermedio: **primeros 3 suscriptores de pago** = validación real.
