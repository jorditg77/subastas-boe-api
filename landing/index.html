El portal oficial, sin el dolor

El BOE publica cada subasta repartida en cuatro pestañas distintas, sin API oficial. Evaluar una sola oportunidad significa abrir pestañas, copiar cifras a mano y calcular umbrales con la calculadora.

GeneralAutoridadBienes / lotesPujas →1 objeto JSON

⚖️ Umbral legal aplicable

Referencias del 50% y 70% calculadas, y en subastas judiciales, cuál aplica según el art. 671 LEC (vivienda habitual sí/no, como lo publica el propio BOE).

📦 Lotes con su economía real

En subastas multi-lote, cada lote llega con su propio valor, depósito y umbrales — igual que en el BOE, pero estructurado.

🛡️ RGPD por defecto

DNI/NIE e IBAN se redactan automáticamente antes de servir cada respuesta.

⚡ Rápido y respetuoso

Caché en memoria con TTL corto: respuestas típicas < 100 ms y una única petición al BOE por búsqueda, por muchos clientes que pregunten.

🔍 Código auditable

El código fuente es público en GitHub (licencia no comercial): puedes ver exactamente qué se extrae y cómo.

📄 Datos oficiales

Fuente: portal público del Boletín Oficial del Estado. Orientativo — verifica siempre con nota simple antes de pujar.

Tu agente de IA, conectado a las subastas

El backend incluye un servidor MCP (Model Context Protocol): Claude, Cursor o cualquier agente compatible puede buscar subastas, pedir el detalle consolidado y calcular umbrales, directamente desde su contexto.

// claude_desktop_config.json
{
  "mcpServers": {
    "subastas-boe": {
      "command": "node",
      "args": ["/ruta/a/subastas-boe-api/src/mcp/server.js"]
    }
  }
}

Tools disponibles: search_auctions · get_auction_detail · calculate_auction_metrics · list_provinces
